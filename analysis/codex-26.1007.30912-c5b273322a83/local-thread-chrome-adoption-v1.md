# 本地线程控件：功能接纳决定

已接纳4个既有源码候选：FSC-0503 线程静态快照分享、FSC-0504 已有子代理内容或总览、FSC-0505 PR详情面板、FSC-0506 停止会话全部后台终端。对应5个用户操作；打开子代理内容与总览分列，interactive/noninteractive保留为内容入口变体。分享准备、发布与复制属于一个用户流程。直接导出的 publishSharedSnapshot 仅保留接口变体，没有证明独立用户入口，不增加操作数。

逐项与既有插件分享、应用深链、Markdown复制、侧聊、会话清理、PR创建/链接/合并及终端展示作了去重。既有功能和操作保持原身份。摘要、重命名和终端展示3项功能只追加源码与4条规格引用。T03拥有分享、子代理和终端协调；T06拥有PR详情，T03消费其入口。两项维护职责仍是提议。

25条源码规格全部未执行，其中1条为直接导出接口合同。当前504项有限功能、571个不同操作、1786条未执行规格、51项任务；106项职责提议和48个粗facade。715条未关联来源身份、20个命令消费者和两套任务图不变。此前线程面板头部与本地控件源码补充继续有效。

分享准备阶段已有暂存上传，发布与复制失败不得混同；终端停止请求只有conversationId，没有单终端ID。保持子代理晚到结果守卫及PR偏好/账户失败fallback。模式、实际后效、PR次级入口、主要行为与独立构建仍待验证。没有新源码解析、REA运行、客户端/模型/服务调用、剪贴板写入或客户端实现。
