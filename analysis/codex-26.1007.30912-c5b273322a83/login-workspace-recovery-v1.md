# 客户端登录与工作区恢复入口

FSC-0511「选择认证方式登录客户端（含工作区恢复入口）」归入 T38。七个操作覆盖浏览器账户登录、API Key 登录、Bedrock 检测与登录、GovCloud 提示、复制登录链接和重试受管理登录方式。提供者、登录/注册及工作区恢复是有明确来源的参数与分支。

`workspaceRecovery=true` 才启用恢复分支；成功后返回经限定的首页/线程交接地址，普通登录继续欢迎流程。返回路径只保留校验通过的 `/browser/handoff` 身份，不能把任意 `next` 当成跳转目标。这个入口本身没有证明项目或历史恢复。

`chatgpt` 与 `api` 在这里表示认证方式，不能据此判断客户端产品模式。保留为 unknown；登录控制器、受管理方式策略、Bedrock 适配和浏览器登录 URL 适配提出四个独立职责。第三方 UI、查询和 schema 通过包依赖引入。

取消语义分别记录：浏览器登录把信号交给认证接口；API Key 只检查本地取消状态，底层调用没有收到信号；Bedrock 检测使用代次过滤过期结果，不能宣称请求已取消。凭据保存、token 权威、浏览器和重启效果仍是具名边界。另保留登录页 Snake 为独立第一方功能候选，尚未计入本目标或分析完成。
