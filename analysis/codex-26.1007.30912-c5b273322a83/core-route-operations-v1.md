计划页没有直接启动任务；本页没有 turnId/侧栏回调，不纳入反馈提交或侧栏打开。Markdown 内部交互仍属于具名渲染依赖边界。文件复制/下载均未实际执行。

登记 Promise 的 finally 会清工作区 Re latch，但同步 factory 异常发生在 finally 安装之前，可能留下 latch；自动继续的 Fe 失败后也不复位。合同保留这些源码差异，没有以统一重试/取消行为覆盖它们。默认项目创建失败没有目录回滚声明，结果消息发送也不能充当接收及持久化通过。

现有环境页添加项目、菜单新建项目、输入框项目菜单、云端差异偏好、线程摘要面板、整段会话复制均保留；按完整目标及状态/接口比较，未按页面名或共享 manager 合并。旧文件变更合同的 Git worker、完整内容一致性、失败/取消及上游生产者缺口继续适用。

当前494项有限功能、548个不同操作（549次功能内出现）、125支撑、1679条未执行规格及51任务；96项限定职责提议加48粗facade不是已恢复模块。968来源身份保留，其中718没有功能关联，含15明确机制；本批减少3条无关联记录，没有把整条功能链判为已验证。

八个冻结程序的最终提取保留125个源码单元；开发时首次未匹配 TemplateLiteral switch 标签，已修正并留存初稿。初稿和最终稿不计为独立发现。第三方实现仅作为分析证据，不生成到维护客户端源码。
