最重要的恢复规则：

- 页面经 `$Kn → DZ(git) → preload → H9 Git bus → qAe → s2` 提交，不能把另一个同名后台 handler 当作必经路径。
- 根目录优先匹配仓库 origin；不匹配时回退到当前 local 项目的第一条 rootPath。页面没有独立目标选择器，这可能选中另一个仓库。
- 默认是非原子 `git apply --3way`；撤销增加 `-R`。另一条 `l3` 路径的 atomic/binary 参数不适用于本页。
- 只有全部成功才切换逐 turn 的已应用标记；部分成功保留原标记并打开详情。关闭详情不撤销、不取消。
- 写入后清理或缓存失效仍可能失败，所以错误、取消或没有响应均不能证明没有改动；不能据超时自动重发。
