本地历史状态为 error 时 Retry 会重载窗口；仅有局部失败标记时则只清标记。分支冲突的 abort 仅抑制晚到导航，没有把 signal 传给分支委托；归档预览 query signal 也没有传给 hydration。离开页面不能计为取消正在执行的任务。

云端 diff effect 调用的 wo 在本基线是空函数，没有由此确认任何差异同步通知。自动标记已读属于机制，不新增用户操作。main 归档页隐藏输入等动作；hotkey直接渲染 Co，不能套用同一归档限制。

提交、取消、归档恢复、分支、删除归档、设置修复、已读和内容查找共九组既有功能关系已复用。复用用户目标不证明它们使用同一 manager/RPC。apply/revert、部分header/turn选择、local chrome及有效provider以四项具名缺口保留，不能算整组页面全部分析完毕。

当前496项有限功能、556个不同操作（557次功能内出现）、125支撑、1709条未执行规格和51项恢复任务；98项限定职责提议加48粗facade不是客户端实现。968来源身份保留，715条没有功能关联，其中15条为明确机制。

八个冻结程序已完成AST提取；本批没有新增REA全量运行、目标求值、客户端启动、模型/服务调用、个人数据读取、剪贴板访问或Git修改。原九项完成标准未提升，完整分析仍未完成。
