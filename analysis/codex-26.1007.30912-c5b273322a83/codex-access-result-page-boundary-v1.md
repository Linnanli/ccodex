# 访问资格结果页的有限结论

`/codex-access` 的静态行为已明确：loading 返回 null；allowed 和 error 返回首页导航元素并设置 replace；denied 懒加载访问受限提示。

提示页显示联系管理员的说明、标题和描述，并提供固定的“了解 Codex”链接。链接传递事件、URL 和 open_in_browser_bridge 发起者给导入的浏览器接口。所选页面没有账户切换、退出登录、套餐购买、提交访问申请或重试资格的控件；此结论不涉及祖先或全局界面。

它与现有额度申请、账户资料展示和退出登录目标不同，形成一个待正式采用的结果页目标。产品模式仍为 unknown、保留；文案与路由名称不能单独证明独占模式。

本批边界结束。实际资格发布者、路由与懒加载后效、外部浏览器结果另列待验证，不因这些未知重复追查通用 provider。

复用已保存路由分析，仅解析两个小程序和一个 42,559 字节的完整初始化函数，共 9,787 个 AST 节点。29 个来源片段逐字节核对。8 条补充规格均未执行；正式功能仍为 505 项、正式未执行规格仍为 1794 条。待将本结论并入正式清单，完整分析及独立构建均未完成。
