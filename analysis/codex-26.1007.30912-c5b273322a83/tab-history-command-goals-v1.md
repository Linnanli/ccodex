# 撤销与标签命令：源码合同及功能采纳

本批核对6个命令ID的6处注册，保存30条静态事实、6条显式ESM连接；来源分析与功能归并同时交付。新增4项有限功能、6个操作、20条未执行规格，原450项定义及全部旧操作/规格身份保持不变。

| 功能 | 关键合同 |
| --- | --- |
| FSC-0453 撤销或重做应用操作 | 默认与键盘路径分开；编辑器优先处理标准键，app历史按scope和queue等待原动作完成，保留过期、导航、错误及stale检查。受理true不代表完成。 |
| FSC-0454 重开最近关闭的面板标签 | 先pop关闭记录；尝试原面板和另一面板；truthy restore还需tabId实际存在。错误重入队并限25条，命令通过ref Promise串行。 |
| FSC-0455 关闭指定面板的其他标签 | 空默认回调之外的contextHandler执行；originPanel可覆盖焦点，触发时读取活动标签并委托controller。 |
| FSC-0456 选择工作区或面板的相邻标签 | context/keyboard分别传参；保留c8n锁、bottom、无workspace的right条件及已有workspace的可见/full判断。 |
