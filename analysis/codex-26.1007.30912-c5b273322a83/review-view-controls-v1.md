# 审查差异视图控件分析

本批完成七类控件的选定源码契约：布局、换行、空白过滤、导入过滤、组展开、词级差异、完整文件加载。归入既有T06，共7个参数化操作、21条未执行规格；全局富预览复用FSC-0495与既有操作/规格，不重复计数。宽按钮与窄菜单共用同一回调。

布局按unified→split→auto→unified循环；auto仅在容器允许split且文件同时有新增和删除行时选择split。词级差异在设置开启且增删总行数不超过2000时使用word-alt。

Hide imports是独立设置，与生成文件过滤不同。其每文件选择器有查找定位例外，et确实消费该选择器；Ne在缺解析器/语言、partial、新增或删除时保留原diff，并保留带行批注的hunk。没有把适配规则误当成第三方解析器实现。

组展开通过review作用域事件写默认状态并清逐文件覆盖；生成文件、deleted和revision折叠仍有各自条件。完整文件开关影响预取、按需加载和缓存身份；磁盘回退另由来源条件控制。关闭开关或折叠文件不证明已经中止worker请求。

拟议维护边界为toolbar/状态协调与diff呈现适配，具名状态键、默认值、imports/exports、共享状态、副作用和依赖边界均见[契约](review-view-controls-v1.json)。第三方以包/接口接入，不生成其实现副本。

11项事实、45个源码见证、6个完整程序、17个ESM身份连接、10项源码检查通过；99个选定单元独立解析，文件哈希/UTF8范围回读通过。这些证明选定代码关系，未执行目标JS、客户端、模型、服务或真实UI。物理存储、有效模式、跨窗口、失败/取消和重启仍待核对。

当前有限清单525功能、603不同用户操作、1912条未执行规格；原39要求、9分析标准、M1–M7及两张依赖图不变。本批源码问题已关闭，后续回到影响功能剥离、原生依赖/构建与主要行为的原计划缺口；不因运行证据缺失继续展开相邻控件。
