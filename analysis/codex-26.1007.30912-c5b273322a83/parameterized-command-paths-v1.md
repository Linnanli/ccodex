# 三组参数化命令的源码链路

本批只核对 focusTab1–9、environmentAction1–9 与三种 page.format 列表命令，共21条声明。三组均已定位到有限生产者、导出/导入或本地表、组件传参、动态注册及回调。旧字面量清单漏掉了这些参数化路径，不能据此判定命令没有消费者。

| 命令族 | 实际来源与注册 | 已查清的效果及边界 |
| --- | --- | --- |
| focusTab1–9 | bP → xP/gmn → Ti.map → Lc → Ln | 传入数组索引；Hji考虑布局及RTL，选择目标并可能调度焦点。目标缺失返回false；一次性快捷键提示另有条件。 |
| environmentAction1–9 | bP → R6n/hmn → bf；HS → JS → YS → Xc | 按平台筛选后的原顺序关联动作，登记时要求动作和会话。HS解析cwd，更新偏好、显示终端，再委托runAction。超过9个动作仍可有runId，不能解释为动作数量上限。 |
| 三种page.format列表命令 | Vr的ID/样式对 → Ur → Wr → _t | 保留写权限、编辑器状态、输入法组合和键盘焦点条件，再请求列表toggle。真实编辑器事务和持久化仍属委托边界。 |

去重结论：编号选择工作区标签与FSC-0394侧边栏线程选择不同；执行环境动作与FSC-0104至0107配置操作不同；三种列表样式暂列一个目标的三个操作。三个目标候选尚未分配功能ID或并入功能账本，页面模式仍unknown。

本批不复制实现、不提交模型、不启动客户端。105处直接调用和7处动态调用的原统计不变，只为其中3处补上21个有限ID的来源。435项功能、1440条未执行规格、825条无功能关联来源均保持原账本；131条命令目标/行为缺口中，21条已有本批源码链，其他110条未在本批处理。

具体范围、哈希、组件参数、回调和剩余缺口见[结构化合同](parameterized-command-paths-v1.json)及[证据](parameterized-command-paths-v1-evidence.jsonl)。下一步只做这三个候选的功能及职责归并，不因真实运行尚未验收而重复追查这些生产者和注册链。
